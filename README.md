# Laboratory-Works-Algorithms-Arzubov-1p-24
З метою оптимізації процесу тестування, демонстрації та захисту лабораторних робіт, окремі тематичні завдання було об'єднано у два наскрізні (монолітні) програмні модулі відповідно до логіки виконання практикуму
Чому було обрано саме таку архітектуру:

Зручність перевірки: Замість почергового відкриття та запуску понад десятка дрібних файлів, викладач може запустити один файл, який послідовно продемонструє роботу всіх алгоритмів дня.

Інтерактивність: У частині геометричних алгоритмів реалізовано динамічне введення даних. Програма зупиняється, очікує на ручне введення координат точок користувачем через консоль, після чого миттєво проводить розрахунки всіма трьома методами та візуалізує фінальну опуклу оболонку на графіку matplotlib.

Чистота коду: З вихідних текстів програм повністю видалено надлишкові коментарі та технічну документацію (docstrings) для забезпечення максимальної читабельності, компактності та відповідності стандартам чистого коду (Clean Code).
